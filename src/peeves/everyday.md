## The test

Try **"each day."** If it fits, you want the two-word version: **every day**.

*I check it each day* works, so *every day*. *These are my each day shoes* doesn't, so *everyday*.

## What the one-word version means

**Everyday** is an adjective meaning ordinary or routine—*everyday problems*, *everyday clothes*. It describes a noun and it never tells you how often something happens.

Same pattern as *anytime* vs *any time* and *awhile* vs *a while*: closing the space turns a phrase into a describing word.
