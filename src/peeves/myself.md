## The test

**Remove the other person and see what survives.**

*Between you and I* → *between I* → wrong, so **me**. *Sam and myself will attend* → *myself will attend* → wrong, so **I**. It works every time and takes a second.

## What "myself" is actually for

Reflexives point back at the subject of the same sentence: *I hurt myself. I'll do it myself.* If you aren't already in the sentence as the one doing the thing, you can't be *myself*.

It's used as a politeness hedge—*please contact myself*—presumably because it sounds more formal than *me*. It sounds more formal the way a wrong answer in a nice font does.
