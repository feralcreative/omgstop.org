summary: "Someone has it worse. That is true of literally everyone."
rule: "The existence of bigger problems does not make this one <em>not a problem</em>."
snark: "Somebody's always got it worse. Including them."
aliases:
  - worse-things
examples:
  - wrong: "\"You're complaining about this? People are starving.\""
    right: "\"Both things can be true. Can we fix this one?\""
    note: "There's always a worse problem, so this would silence every complaint forever."

Also "appeal to worse problems." Taken seriously it would permit exactly one complaint worldwide—from whoever currently has it worst—which is a decent sign the reasoning is broken.

Problems aren't ranked into a queue. Fixing a small one rarely uses up the capacity to fix a large one, and usually the person saying this isn't working on the larger problem either.
